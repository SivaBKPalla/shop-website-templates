# Shop website templates

Two one-page websites you can text to a business as a sample, then change to their shop.

- Barber shop: [barber/](barber/)
- Nail and beauty salon: [salon/](salon/)

Live pages, after GitHub Pages is on:

- https://sivabkpalla.github.io/shop-website-templates/
- https://sivabkpalla.github.io/shop-website-templates/barber/
- https://sivabkpalla.github.io/shop-website-templates/salon/

## Make a page for one shop

1. Duplicate the `barber` or `salon` folder.
2. In `index.html`, replace every block marked `EDIT`.
3. In `app.js`, change `phoneTel` to the shop’s real number, digits only, with `+1` in front.
4. Send the new link. The booking form opens a text message to that number.

The shop names on these pages, Atlas Barber Co. and Lumen Nail Studio, are samples. They are not real businesses.
